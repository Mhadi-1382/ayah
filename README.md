# ayah

*The **Ayah application** is a practical tool in the field of the Quran. Users can access and benefit from its features both online and offline. In designing its user interface, a combination of traditional Islamic geometric art and modern design principles has been adopted to create a more engaging and user-friendly experience.
<br />
<br />
Ayah is essentially a web application. The primary reason for developing it using web technologies is to provide easy, fast, and unrestricted access while also supporting offline functionality through Progressive Web App (PWA) technology.
<br />
<br />
The application's back-end framework is built using Python and Django, which help enhance the security of both the server and the application itself.*
